Data dictionary & metric definitions

Required CSV header: id,client,service,amount,stage,date. Unique IDs; nonnegative INR amounts; stages Lead, Proposal, Won or Lost; valid YYYY-MM-DD dates. Dates represent deal creation. Total value sums all filtered deals. Open pipeline sums Lead and Proposal. Won value sums Won. Win rate is Won count divided by Won + Lost count, or unavailable when no deals are closed. Uploaded files replace the current dataset only after complete validation. All content is fictional until you import your own data. Browser storage is not a shared or secure multi-user CRM.
