# YouTube demo run of show

Opening: “Here are five things you can build with AI and offer to real customers. Each comes with a working demo and a reusable skill. I’ll show you the result, who it helps and how to customize it.”

## 1. The website glow-up
Show Northline's hero, services and enquiry. Then show SaaSpo and a chosen reference. Explain: “A vague prompt can produce a generic website. Pick a visual reference, then have the skill extract the layout, typography and spacing before it builds your version.” Paste the README website prompt. Buyer: a local service business. Test offer: ₹5,000–₹12,000, labelled as your proposed price, not a market guarantee.

## 2. The instant quote
Show Still & Story: intimate preset ₹10,000; add album -> ₹16,000; signature -> ₹34,000; whole story -> ₹76,000. Download the estimate and show the excluded-cost note. Buyer: a photographer or another service business with an approved rate card. Test offer: ₹4,000–₹10,000.

## 3. The creator's calling card
Show Alex Mercer's collectible profile card and audience charts. Select the product walkthrough to move the total from $300 to $650. Configure a partnership for a fictional brand, create the brief and download it. Print/save the media kit. Call all metrics sample data. Buyer: creators already pitching sponsors. Test offer: ₹3,000–₹8,000.

## 4. From CSV to clarity
Show sample.csv, import it, filter to Won, and compare the metric with the underlying rows. Clear filters, add a deal, change its stage, export and optionally save locally. Explain dashboard vs local CRM. Credit the frontend-design and wshobson kpi-dashboard-design skills. Buyer: small agencies or service teams doing repetitive reports. Test offer: ₹5,000–₹15,000.

## 5. The invitation to remember
Show Elena & Theo's garden invitation, countdown and schedule. Download the calendar file. Prepare an RSVP and explain that it opens a message draft after contact setup. Credit the MIT upstream template. Buyer: couples, photographers and invitation designers. Test offer: ₹2,000–₹6,000.

End: “Choose one offer, customize one demo and show it to a relevant customer. The first sale is an experiment, not a guaranteed outcome.”

Use actual screen recordings. Don't claim these demos were generated by a particular free model unless you actually record and verify that run. Price overlays should say “suggested offer to test.” Never present illustrative metrics or enquiries as customers, income or delivered responses.

## Presenting the examples

Open the main slideshow, use F for fullscreen (if supported) and the left/right arrows to move through ideas. Each slide has a demo link and a Copy build prompt button. Show the real interaction in each demo, then return to the next chapter. The car, garden and avatar visuals are generated examples, not real client work. Do not call the drafts a sent enquiry, a paid sponsorship, or a confirmed RSVP.
